      On the team? Sign in with your personal quest key to add and move tasks here. Assistants can do the same from a script:
      curl -X POST https://the-dungeon-door.vercel.app/api/quests \ -H "x-quest-key: $QUEST_KEY" -H "content-type: application/json" \ -d '{"title": "What needs doing", "area": "rules", "milestone": "armory", "owner": "unclebob"}'
      Change one with PATCH /api/quests?id=… (for example {"status": "done"}). Read the whole board with GET /api/quests.
