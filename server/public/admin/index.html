        The quest log speaks MCP

        Any assistant that supports the Model Context Protocol can read the board and manage tasks, levels and workstreams as you. It connects to this address and signs in with your personal quest key:

        
      
        
      
        
        
        Claude Code
        
        
        
        
        Inside this repository it is already configured: export QUEST_KEY in your shell and Claude Code picks the server up from .mcp.json.
        
      
        
      
        
        
        Cursor and other clients
        
        
        
        
        A streamable HTTP server with one header. Everything the assistant does is recorded under the key's owner.
        
      
        
      
        
        
        Without MCP
        
        
        
        
        The same key works with the plain API. How assistants should use the board is written up in the repository's README.
        
      
        
      
        
        
        The team
        
        
        
        
        Admins can also change levels, workstreams and the headline. Members manage tasks.
